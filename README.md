Домашнее задание к работе 11: Структуры данных (Вариант 5)
Условие задачи
Создать структуру для хранения записи «Автомобиль» (Марка, Производитель, Тип, Год выпуска, Дата регистрации). Организовать ввод 5-10 различных записей. Из полученного массива структур найти и напечатать информацию о машинах марки "Toyota" и зарегистрированных до 2007-го года.

1. Алгоритм и блок-схема
Алгоритм
Начало

Объявление структуры Car:

brand[50] — Марка автомобиля.

manufacturer[50] — Производитель.

type[50] — Тип кузова.

year (int) — Год выпуска.

reg_year (int) — Год регистрации.

Ввод данных:

Инициализировать массив структур (например, из 6 записей) тестовыми данными.

Вычисления (обработка):

Пройти по массиву в цикле.

Проверить условие: если марка равна "Toyota" (через strcmp) И год регистрации меньше 2007 (reg_year < 2007), то вывести информацию об автомобиле и установить флаг found = 1.

Вывод результатов:

Если флаг found остался равен 0, вывести сообщение "Машин с такими параметрами не найдено".

Конец

Блок-схема
(Здесь вы можете вставить свою блок-схему, как в оригинале. Если её нет, этот раздел можно оставить пустым или просто написать "Блок-схема прилагается отдельным файлом")

2. Реализация программы
c
#include <stdio.h>
#include <locale.h>
#include <string.h>

// Структура для хранения записи "Автомобиль"
struct Car {
    char brand[50];       // Марка автомобиля
    char manufacturer[50];// Производитель
    char type[50];        // Тип
    int year;             // Год выпуска
    int reg_year;         // Дата регистрации (год)
};

int main() {
    setlocale(LC_ALL, "RUS"); // Для корректного вывода кириллицы

    // Массив структур с 6 записями
    struct Car cars[6] = {
        {"Toyota", "Toyota Motor Corp", "Седан", 2005, 2006},
        {"BMW", "BMW AG", "Внедорожник", 2008, 2008},
        {"Toyota", "Toyota Motor Corp", "Кроссовер", 2010, 2011},
        {"Toyota", "Toyota Motor Corp", "Хэтчбек", 2004, 2005},
        {"Audi", "Audi AG", "Универсал", 2006, 2007},
        {"Toyota", "Toyota Motor Corp", "Седан", 2006, 2008}
    };

    int count = 6; // Количество записей
    int found = 0; // Флаг, нашли ли мы подходящую машину

    printf("--- Сведения о машинах марки 'Toyota', зарегистрированных до 2007 года ---\n\n");

    for (int i = 0; i < count; i++) {
        // Условие: Марка "Toyota" И год регистрации < 2007
        if (strcmp(cars[i].brand, "Toyota") == 0 && cars[i].reg_year < 2007) {
            
            printf("Марка: %s\n", cars[i].brand);
            printf("Производитель: %s\n", cars[i].manufacturer);
            printf("Тип: %s\n", cars[i].type);
            printf("Год выпуска: %d\n", cars[i].year);
            printf("Год регистрации: %d\n", cars[i].reg_year);
            printf("----------------------------------------\n");
            
            found = 1;
        }
    }

    if (!found) {
        printf("Машин с такими параметрами не найдено.\n");
    }

    return 0;
}
